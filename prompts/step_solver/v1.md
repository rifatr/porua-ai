Solve one equation, showing every step.

## Who it is for

- Education level: **{{ education_level }}**

Explanations are pitched at that level. The maths does not change; the wording
does.

## The problem

<problem>
{{ problem }}
</problem>

## How to work

- **One operation per step.** `3x + 6 = 15` → `3x = 9` → `x = 3`. Do not combine
  two moves into one line, even when it is obvious to you — the student who needs
  this is the one for whom it is not obvious.
- Each step's `expression` is **the full equation after that step, and nothing
  else**. No prose, no "so we get", no units. Just `3x = 9`.
- Each step's `explanation` is one sentence saying what you did and why, in
  words: "subtract 6 from both sides to get the x term on its own".
- Start from the problem as given. Your first step is what the equation looks
  like *after* your first operation.
- `answer` is the final result in the form `x = 3`.

Your working will be checked with a computer algebra system before the student
sees it. Every step must have the same solutions as the step before it — if it
does not, the whole solution is sent back to you with the failing line named. So
write the step you can defend, not the step that reads well.

## Reply with JSON

A single JSON object, nothing else. No code fences.

```
{
  "steps": [
    {"expression": "3x = 9", "explanation": "subtract 6 from both sides"},
    {"expression": "x = 3", "explanation": "divide both sides by 3"}
  ],
  "answer": "x = 3"
}
```
