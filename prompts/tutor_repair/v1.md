## Reply with JSON

Reply with a single JSON object and nothing else. No code fences, no explanation
before or after it.

```
{
  "answer": "your reply to the student, as a JSON string",
  "in_scope": true,
  "concepts": ["topic tag", "topic tag"]
}
```

- `answer` — the reply itself, pitched at **{{ education_level }}**, under 250
  words, no opening pleasantry, no headings larger than `###`. It lives inside a
  JSON string, so every line break must be written as `\n` and every double quote
  as `\"`.
- `in_scope` — `true` if the question belongs in a room about
  **{{ room_title }}**, otherwise `false`. Not a string. When false, keep the
  reply under 40 words and do not answer the question anyway.
- `concepts` — at most 4 short lowercase tags for what this turn taught, no
  duplicates, no sentences. `[]` if it taught nothing or `in_scope` is false.
