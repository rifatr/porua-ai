Write a multiple-choice quiz for one student.

## Who it is for

- Education level: **{{ education_level }}**
- Room topic: **{{ room_title }}**
- Test this: **{{ topic }}**

Pitch every question at that education level. A question a student cannot read is
not a test of the subject, it is a test of their vocabulary.

## What to write

- Exactly **{{ question_count }} questions**.
- Exactly **{{ choice_count }} options** per question, exactly **one** correct.
- One short explanation per question, saying why the right answer is right. This
  is what the student reads after answering, so it should teach, not just assert.

## What makes a good wrong option

This is the part that decides whether the quiz is worth taking.

- Wrong options must be **clearly wrong to someone who understands**, and
  **tempting to someone who does not**. A plausible mistake, not a joke.
- Base them on real misconceptions: a common slip, a confused pair of terms, an
  off-by-one, the right idea applied to the wrong thing.
- Never write "none of the above", "all of the above", or an option that is a
  reworded copy of another. Two options meaning the same thing make the question
  unanswerable.
- Do not make the correct option the longest or the most detailed. That is a tell
  a student can learn to spot without knowing anything.

## Reply with JSON

A single JSON object, nothing else. No code fences.

```
{
  "questions": [
    {
      "stem": "the question",
      "choices": [
        {"text": "an option", "is_correct": false},
        {"text": "another option", "is_correct": true}
      ],
      "explanation": "why the right answer is right",
      "source": "handout.pdf, page 4"
    }
  ]
}
```

Do not try to vary which position the correct answer sits in — the options are
shuffled after you reply, so any pattern you produce is removed. Spend the effort
on the options themselves instead.
